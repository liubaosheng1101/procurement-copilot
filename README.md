# 采购决策助手 · 网页版

面向采购从业者的**纯前端离线计算器**：把比价、价格分析、供应商评分、库存补货、进口到岸成本这五类日常决策，做成打开浏览器就能用的小工具。

## 在线使用

👉 **[https://liubaosheng1101.github.io/procurement-copilot/](https://liubaosheng1101.github.io/procurement-copilot/)**

无需注册、无需安装，手机和电脑浏览器均可使用。

## 功能模块

| 模块 | 解决什么问题 |
|---|---|
| **报价比价** | 把含税/未税、运费、账期拉成同一口径，算出每家的到厂单位成本与年度总成本并排名 |
| **价格分析** | 按期间汇总加权均价、环比、波动率，计算 PPV（采购价差）与供应商份额 |
| **供应商评分** | 先过门槛（不通过直接淘汰），再按权重对各项指标做 min-max 归一后加权算总分 |
| **库存补货** | 按需求与提前期的双波动计算安全库存、再订货点，并给出受 MOQ / 订货倍数约束的建议下单量 |
| **进口到岸成本** | 测算货值、国际运费、保险、关税、进口增值税等，得出 landed cost（到岸总成本） |

## 特点

- **纯本地计算**：所有运算在浏览器内完成，不连接任何服务器
- **不联网、不上传数据**：报价、供应商、价格等敏感数据不会离开你的设备
- **零依赖、单文件**：整个工具就是一个 HTML 文件，下载后离线也能用
- **免费**

## 本地使用

1. 下载本仓库的 `index.html`
2. 用浏览器直接打开即可，无需任何环境
